## Phase 2 — المهمة الأولى المعتمَدة (قيد البدء)

**ترحيل أوامر الإدارة المتبقية لـSupabase:**
- `/admin/list` — يحتاج قدرة استعلام كاملة (لا فقط `list_all_codes`، بل تفاصيل كل سجل)
- `/admin/revoke` — الجزء المحلي (`licenses.json`) يُحذَف بعد نجاح الترحيل الكامل، يبقى المسار الإداري على Supabase فقط
- `/admin/pause_all` — نفس الملاحظة
- `/admin/extend` — غير موصولة بـSupabase إطلاقًا بعد؛ تحتاج دالة إدارية جديدة تتجاوز فحص الملكية (تناظر `admin_force_revoke`)

**بعد نجاح الترحيل الكامل:** حذف `licenses.json` نهائيًا — Supabase يصبح Single Source of Truth بلا استثناء.

## Phase 2 — المهمة الثانية المعتمَدة (بعد الأولى)

**نظام صلاحيات المشرفين:** Owner → Moderators → Customers. المالك (Owner) فقط يضيف/يعطّل/يحذف المشرفين (عبر Telegram ID أو آلية تُحدَّد). المشرفون هم من ينشئون ويفعّلون الأكواد للعملاء — لا الـOwner مباشرة. **لا واجهة ويب، لا Dashboard، لا أي ميزة خارج هذا النطاق بهذي المرحلة.**
